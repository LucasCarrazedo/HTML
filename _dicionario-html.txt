DICIONÁRIO DE HTML

TAGS BÁSICAS
html - Define o documento HTML
head - Contém metadados do documento
body - Contém o conteúdo visível
title - Define o título da página
meta - Define metadados
link - Vincula recursos externos
script - Incorpora ou referencia JavaScript
style - Define estilos CSS

TAGS DE TEXTO
h1, h2, h3, h4, h5, h6 - Cabeçalhos de diferentes níveis
p - Parágrafo
a - Link/âncora
strong - Texto em negrito (semântico)
b - Texto em negrito
em - Texto em ênfase/itálico (semântico)
i - Texto em itálico
br - Quebra de linha
hr - Linha horizontal
span - Container inline genérico
div - Container block genérico

LISTAS
ul - Lista desordenada
ol - Lista ordenada
li - Item de lista
dl - Lista de definições
dt - Termo de definição
dd - Descrição de definição

FORMULÁRIOS
form - Define um formulário
input - Campo de entrada
textarea - Área de texto multilinha
button - Botão
label - Rótulo para inputs
select - Menu suspenso
option - Opção em um select
fieldset - Agrupa elementos de formulário
legend - Título de um fieldset

TABELAS
table - Define uma tabela
tr - Linha de tabela
td - Célula de tabela
th - Célula de cabeçalho de tabela
thead - Cabeçalho de tabela
tbody - Corpo de tabela
tfoot - Rodapé de tabela
caption - Título de tabela

MÍDIA
img - Imagem
video - Vídeo
audio - Áudio
source - Fonte de mídia
figure - Figura/ilustração
figcaption - Legenda de figura

SEMÂNTICA
header - Cabeçalho de página/seção
footer - Rodapé de página/seção
nav - Navegação
main - Conteúdo principal
article - Artigo independente
section - Seção genérica
aside - Barra lateral/conteúdo relacionado

ATRIBUTOS COMUNS
id - Identificador único
class - Classe(s) CSS
style - Estilos inline
title - Texto de tooltip
data-* - Atributo customizado
href - URL para links
src - Caminho para recurso
alt - Texto alternativo para imagens
disabled - Desativa elemento
readonly - Torna campo somente leitura
required - Marca campo como obrigatório
placeholder - Texto de placeholder em inputs
type - Tipo de elemento (input, button, etc)

CARACTERES ESPECIAIS
&lt; - <
&gt; - >
&amp; - &
&quot; - "
&apos; - '
&nbsp; - Espaço não-quebrável
